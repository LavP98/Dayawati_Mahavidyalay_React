# Dayawati Mahavidyalay (React)

Modern React rebuild of the Dayawati Mahavidyalay college website, featuring an Ayodhya-inspired theme (saffron, maroon, and gold palette).

## Features

- All original content preserved: courses, quick links, contact info, vision/mission, carousel images
- Admission notice and pamphlet popups (English/Hindi)
- Responsive design with mobile navigation
- Auto-rotating image carousel
- Ayodhya heritage theme with modern college aesthetics

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

## Build

```bash
npm run build
npm run preview
```

## Original Project

This React version is based on the Angular project in the parent folder, reusing all assets and content as-is.
